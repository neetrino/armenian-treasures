# 03 — Map — քննարկում Վլադի հետ

**Բաժին:** Home page  
**Կարգավիճակ:** Blocked  
**Առաջընթաց:** չի գնահատվում (քննարկում)

## Ինչ է պահանջվում

Sheet-ում գրված է՝ «Map-ի հարցով կքննարկենք Վլադի հետ»։ Սա իրականացման ticket չէ, մինչև չլինի որոշում։

## Ինչպես իրականացնել (որոշումից հետո)

Ներկա հիմքը՝

- Home preview — `components/sections/HeritageMapSection.tsx`
- Full page — `app/(public)/map/page.tsx`, `components/map/*`
- API — `app/api/map/route.ts`
- Ֆիլտրեր — `lib/constants/heritage-map-filters.ts`

Քննարկումից հետո այս ֆայլում ամրագրել որոշումը (pin style, filters, immersion, dataset) և նոր % դնել։

## Իրականացված է հիմա

- `/map` և home map preview կան։
- Sheet-ի նոր պահանջը դեռ սահմանված չէ։
